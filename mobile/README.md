# Apps nativos

Não há Expo Go nem React Native.

- `seller-native`: Android/Kotlin para vendedor externo.
- `driver-native`: Android/Kotlin para motorista.

O backend padrão para emulador Android é `http://10.0.2.2:3000`.
Em aparelho físico, substitua por IP/hostname acessível na rede local.

O ambiente de entrega não possui Android SDK/Gradle, portanto os APKs não foram compilados nesta sessão. Os projetos são fontes nativos para abertura no Android Studio.
